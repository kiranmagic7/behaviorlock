# Support

Community support is best effort.

Use GitHub Discussions for setup questions and design conversation. Use issue forms for reproducible bugs, behavior gaps, false positives, and feature proposals.

Private vulnerability reports belong in [GitHub Security Advisories](https://github.com/kiranmagic7/behaviorlock/security/advisories/new).

Before requesting help, run:

```bash
behaviorlock version
behaviorlock doctor
go test ./...
```

Share sanitized output only. Remove package registry credentials, filesystem usernames, home paths, tokens, and private repository names.
